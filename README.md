# TURNOS SaaS

**Adquisición → Reserva → Agenda → Cliente → Repetición**

Commercial Site v1 for TURNOS SaaS.

## Objetivo

Presentar TURNOS como un producto SaaS de reservas para PyMEs, con foco en conversión comercial y una separación explícita entre capacidades actuales y futuras.

## Stack

- Next.js
- React
- TypeScript
- Lucide React
- CSS responsive propio

## Estado

- `main`: baseline original.
- `feat/commercial-site-v1-hardening`: hardening comercial/UX de la landing.
- Sin credenciales de producción.
- Sin dependencia de backend para la landing comercial.

## Criterios

No inventar integraciones ni funcionalidades no implementadas. Las futuras integraciones deben conectarse posteriormente al backend/API de TURNOS.
